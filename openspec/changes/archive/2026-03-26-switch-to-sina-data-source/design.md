# 数据源切换设计

## 背景

当前系统使用东方财富作为主要数据源,腾讯财经作为指数数据源,akshare 作为备用。东方财富存在以下问题:
1. 使用 curl 绕过代理,需要解析 JavaScript 对象
2. 服务器不稳定,可能返回空响应
3. 代码复杂,维护困难

## 目标

将金融数据源从东方财富切换到新浪财经,提高系统稳定性和性能.

## 枇术方案

### 1. 新浪数据源客户端

新增 `SinaFinanceClient` 类:
- 使用 httpx 或 curl 直接访问新浪 API
- 无需解析 JavaScript 对象
- 支持代理和无代理模式

API 端点:
```
指数数据: https://hq.sinajs.cn/quotes.php?format=text&list=sh000001,sz399001,sz399006
A股列表: https://hq.sinajs.cn/list/ (需要研究)
```

数据格式 (示例):
```
指数: var hq_str_sina = "s_sh000001,上证指数,3957.05,-49.50,-1.24,..."
A股: var hq_str_sina = "sz000001,平安银行,10.5,0.5,..."
```

### 2. FinanceClient 修改

调整数据源优先级:
- 主数据源: SinaFinanceClient
- 备用数据源1: TencentFinanceClient (仅指数)
- 备用数据源2: akshare

### 3. 数据源优先级

```
┌─────────────────────────────────────────────────────────┐
│                   FinanceClient                        │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────────┐    ┌─────────────────┐          │
│  │ SinaFinanceClient │    │ TencentFinance  │    akshare │
│  │ (主数据源)         │    │ (备用 - 指数)  │  (备用)    │
│  │                   │    │                   │          │
│  │ • 指数数据         │    │ • 指数数据         │          │
│  │ • A股列表         │    │                   │          │
│  │ • 成交额           │    │                   │          │
│  │ • 涨跌统计         │    │                   │          │
│  │ • 板块数据         │    │                   │          │
│  └────────────────────┘    └──────────────────────────┘          │
└─────────────────────────────────────────────────────────┘
```

### 4. 兼容性考虑

- 保持 API 接口不变
- 数据格式转换层处理数据源差异
- 现有测试兼容新数据源

## 风险与缓解

| 风险 | 缓解措施 |
|-----|---------|
| 新浪 API 限流 | 添加重试逻辑,使用备用数据源 |
| 网络问题 | 使用 curl 绕过代理 |
| 数据格式变化 | 数据映射层 |

## 测试策略

1. 单元测试: 测试新浪客户端的各个方法
2. 集成测试: 测试 FinanceClient 的数据源切换
3. 手动测试: 在实际环境测试数据获取

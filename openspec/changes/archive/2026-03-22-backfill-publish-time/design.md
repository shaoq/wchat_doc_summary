## Context

数据库中存在 publish_time 为空的旧文章，需要在 fetch 完成后批量补充这些数据

## Goals / Non-Goals

**Goals:**
- 自动更新空发布时间的文章
- 支持手动触发更新

**Non-Goals:**
- 不修改现有抓取逻辑
- 不重新抓取文章内容

## Decisions

### 1. 更新时机
- **决定**: 在 fetch 完成后批量更新
- **理由**: 避免每次 fetch 都检查所有文章，### 2. CLI 命令
- **决定**: 添加 `wchat backfill <mp_id>` 命令
- **理由**: 支持手动触发，灵活性强

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|----------|
| API 调用失败 | 跳过失败文章，继续处理其他 |
| 部分文章无法获取时间 | 记录日志，用户可手动补充 |

# Sector Data API Specification

## 概念板块 API

### 端点
```
GET http://82.push2.eastmoney.com/api/qt/clist/get
```

### 参数
| 参数 | 类型 | 说明 |
|------|------|------|
| fid | string | 排序字段，默认 `f62` |
| po | string | 排序方向，`1`=升序 |
| pz | string | 每页条数，默认 `500` |
| pn | string | 页码，默认 `1` |
| np | string | 未知，默认 `1` |
| fltt | string | 未知，默认 `2` |
| invt | string | 未知，默认 `2` |
| fs | string | 市场代码，`m:90+t:2` = 概念板块 |
| fields | string | 返回字段列表 |

### 返回字段
| 字段 | 说明 |
|------|------|
| f12 | 板块代码 |
| f14 | 板块名称 |
| f2 | 最新价 |
| f3 | 涨跌幅 |
| f4 | 涨跌额 |
| f5 | 成交量(手) |
| f6 | 成交额 |
| f15 | 最高价 |
| f16 | 最低价 |
| f17 | 今开 |
| f18 | 昨收 |
| f62 | 主力净流入 |
| f66 | 超大单净流入 |
| f69 | 超大单净占比 |
| f72 | 大单净流入 |
| f78 | 中单净流入 |
| f84 | 小单净流入 |

### 响应格式
```json
{
  "data": {
    "diff": [
      {
        "f12": "BK0428",
        "f14": "网络安全",
        "f2": 1523.45,
        "f3": 2.35,
        ...
      }
    ],
    "total": 300
  },
  "rc": 0
}
```

## 行业板块 API

### 端点
```
GET http://82.push2.eastmoney.com/api/qt/clist/get
```

### 参数
| 参数 | 类型 | 说明 |
|------|------|------|
| fs | string | 市场代码，`m:90+t:3` = 行业板块 |
| ... | ... | 其他参数同概念板块 |

### 响应格式
同概念板块

## 错误处理

### HTTP 错误
- 429: 请求过于频繁，等待后重试
- 500+: 服务器错误，降级到 akshare

### 数据错误
- 空数据: 返回空列表
- 格式错误: 记录日志，降级到 akshare

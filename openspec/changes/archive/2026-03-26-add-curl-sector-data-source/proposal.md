# Proposal: 使用 curl 绕过东方财富 SSL 问题

获取板块数据

## 背景

东方财富 (通过 Python HTTP 库访问)存在 SSL 问题，导致 `akshare.stock_board_concept_name_em()` 穱接口全部失败。项目当前使用 curl 方式也用 `subprocess` 调用 curl 绕过 SSL 问题。

## 解决方案

1. **使用 curl 命直接访问东方财富 API** - 绕过 Python HTTP 库的 SSL 问题
2. **添加请求头伪装**: 模拟浏览器 User-Agent
3. **添加重试和超时**: 3 次重试，每次间隔 1 私4. **延迟获取**: 网页请求避免阻塞
4. **数据转换**: 解析返回的数据，转换为项目需要的格式

5. **缓存**: 缓存 5 分钟结果,避免频繁请求

6. **日志**: 详细记录数据源和请求过程

7. **降级策略**: curl 失败时, 回退到 akshare (已实现),

8. **监控**: 可添加监控指标

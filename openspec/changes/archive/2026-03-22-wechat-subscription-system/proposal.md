# Proposal: 微信公众号文章订阅系统

## Summary

实现一个微信公众号文章订阅系统，支持通过微信读书代理 API 订阅公众号、自动抓取文章、存储分析，并集成 AI 智能处理功能。

## Motivation

用户需要：
1. 订阅指定的微信公众号
2. 自动抓取该公众号的文章
3. 数据存储和分析
4. AI 智能处理（摘要、关键词、分类）

**约束条件**：
- 用户没有微信公众号（订阅号/服务号）
- 无法使用微信公众平台 API
- 需要使用 Python 实现

## Proposed Solution

使用 **微信读书代理 API** 方案：
- 只需个人微信扫码登录微信读书
- 可获取任意公众号文章
- 无需拥有公众号

```
│ - 公众号搜索 │    │ - 文章存储   │    │ - 关键词提取 │

```

## Scope

### In Scope
- 微信读书登录认证（二维码扫码）
- 通过文章 URL 订阅公众号
- 文章列表获取和内容抓取
- SQLite 数据存储
- AI 摘要、关键词提取、智能分类
- CLI 命令行工具
- 定时抓取调度

### Out of Scope
- Web UI 界面
- 多账号管理
- 消息推送通知
- 直接通过公众号名称搜索（API 限制）

## Risks and Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| 微信读书 Token 过期 | 无法获取文章 | 实现过期提醒，用户重新登录 |
| 账号被封控 (429) | 临时无法使用 | 请求限频，延迟控制 |
| 代理服务不稳定 | API 不可用 | 支持自定义代理地址 |
| 文章内容获取失败 | 内容缺失 | 重试机制，错误日志 |

## Dependencies

- Python 3.10+
- httpx (HTTP 客户端)
- SQLAlchemy + aiosqlite (异步数据库)
- Click + Rich (CLI)
- OpenAI / Anthropic API (AI 功能)
- 微信读书代理服务 (https://weread.111965.xyz)

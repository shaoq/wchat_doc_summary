## Context

当前 `extract_stocks` 命令输出详细格式的股票报告，包含每篇文章的标题和提取的股票。用户需要一个简化的输出格式，仅包含股票名称和代码，便于快速查看。

## Goals / Non-Goals

**Goals:**
- 添加 `--simple-info` 参数控制简化格式输出
- 默认行为不变（只输出详细格式）
- 指定参数时同时输出详细格式和简化格式

**Non-Goals:**
- 不改变现有的详细格式输出

## Decisions

### 参数设计

**选择**: 使用 flag 参数 `--simple-info`
**理由**: 简单的开关参数，不需要额外值

### 输出文件命名

**选择**: `{mp_id}_stocks_{yymmdd}_info.txt`
**理由**: 在原文件名后加 `_info` 后缀，易于识别和关联

### 输出格式

**选择**: 每组 10 个股票，用逗号分隔
```
股票列表（共 N 只）
==================================================

第 1 组:
股票名(代码),股票名(代码),...

第 2 组:
...
```

**理由**: 用户明确要求的格式，10 个一组便于阅读

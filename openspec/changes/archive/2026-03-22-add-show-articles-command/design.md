## Context

当前 `info` 命令仅显示最新 5 篇文章的摘要，用户无法查看完整文章列表。需要在 `src/cli.py` 中添加新的 `show` 命令，复用现有的 SQLAlchemy 查询模式和 Rich 表格组件。

## Goals / Non-Goals

**Goals:**
- 提供分页查看文章列表的能力
- 支持一次性显示全部文章
- 复用现有代码模式（类似 `info` 命令的查询逻辑）

**Non-Goals:**
- 不添加过滤/搜索功能（后续可扩展）
- 不修改文章数据结构
- 不添加导出功能

## Decisions

### 1. 命令设计
- **决定**: 使用独立 `show` 命令而非扩展 `info`
- **理由**: `info` 专注订阅元信息，`show` 专注文章列表，职责分离更清晰

### 2. 分页实现
- **决定**: 使用 `--limit`/`--offset` 参数
- **替代方案**: 考虑过 `--page` 参数，但 offset 更灵活，支持任意起点跳转

### 3. 输出格式
- **决定**: 表格形式，包含 ID、标题、链接、发布时间
- **理由**: 与 `list` 命令风格一致，Rich Table 组件原生支持

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|----------|
| 大量文章时 `--all` 可能卡顿 | 用户主动使用，期望明确；后续可加警告 |
| 标题/URL 过长影响表格布局 | 截断显示，保持表格整洁 |

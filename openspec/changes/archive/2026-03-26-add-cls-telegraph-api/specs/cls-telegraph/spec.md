# 财联社电报 API 规格

## 功能需求

### 1. 获取电报快讯列表

系统应当能够从财联社获取实时财经电报快讯。

#### Scenario: 成功获取快讯

- **WHEN** 用户请求获取电报快讯
- **THEN** 系统返回快讯列表，每条包含标题、内容、发布时间、相关主题

- **SHOULD** 返回最近 50 条快讯

- **SHOULD** 支持按重要性排序（1-3 级）

### 2. 主题过滤

系统应当支持按关键词筛选快讯。

#### Scenario: 过滤科技类新闻

- **WHEN** 用户指定关键词如 "人工智能"、"芯片"
- **THEN** 系统返回包含这些关键词的快讯

### 3. 时间范围查询

系统应当支持获取指定时间范围内的快讯。

#### Scenario: 查询今日快讯

- **WHEN** 用户请求今天 09:00 之后发布的快讯
- **THEN** 系统返回该时间段内的快讯

## 非功能性需求

### 1. 缓存

快讯数据应缓存 5 分钟以减少重复请求。

### 2. 错误处理

API 请求失败时应有适当的错误处理和重试机制。

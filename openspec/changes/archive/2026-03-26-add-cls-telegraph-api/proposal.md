# 财联社电报 API 集成

## 背景

微信公众号订阅系统目前只抓取微信公众号文章并处理。没有实时财经快讯获取能力。

## 目标

集成财联社电报 API，获取实时财经快讯数据，支持：
- 快讯推送（如涨停、异动提醒）
- 市场情绪监控
- 快讯分类（按主题/板块）

## 范围

### 数据源
- 财联社电报 API（https://www.cls.cn/telegraph）

### 功能需求
1. 获取电报快讯列表
2. 支持主题过滤（按关键词）
3. 支持时间范围查询
4. 缓存机制避免频繁请求

### 非功能性需求
1. 与现有 FinanceClient 集成
2. 保持与现有 API 风格一致
3. 支持配置化开关

## 影响范围

- 新增 API 宙户 `/src/api/cls_telegraph.py`
- 更新 FinanceClient 集成新数据源
- 配置项（可选）

## 风险

- API 稳定性：财联社服务可用性
- 数据准确性：需验证返回数据格式
- 请求频率：需遵守限制

## 验收标准

1. 电报快讯获取成功
2. 主题过滤准确
3. 时间范围查询正确
4. 缓存工作正常

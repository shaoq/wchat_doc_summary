## Why

当前 fetch 功能会抓取公众号的所有历史文章，这在实际使用中存在两个问题：

1. **效率低下**：每次抓取都会遍历大量历史文章，浪费 API 请求配额
2. **数据冗余**：已抓取的文章会被重复检查，增加数据库查询负担

用户通常只关心最近的文章，因此需要优化为默认只抓取最近 5 天的文章。

## What Changes

- 新增 `--days` 参数，支持指定抓取最近 N 天的文章（默认 5 天）
- 新增 `--full` 参数，支持抓取全部历史文章（保留原有行为）
- 优化 `fetch_feed` 方法，支持时间范围过滤
- 更新 CLI 命令帮助信息

## Capabilities

### New Capabilities

无新增能力，仅优化现有实现。

### Modified Capabilities

- `article-fetcher`: 修改抓取逻辑，增加时间范围过滤功能
  - 新增 `days` 参数控制抓取范围
  - 新增 `full` 参数保留全量抓取能力
  - 默认行为从"抓取全部"改为"抓取最近 5 天"

## Impact

- **CLI 命令**: `wchat fetch` 行为变更，默认只抓取最近 5 天
- **API**: `FetcherService.fetch_feed()` 方法签名变更
- **向后兼容**: 使用 `--full` 参数可恢复原有全量抓取行为
